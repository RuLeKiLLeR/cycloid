# Update Docs

Use when the task asks to write, audit, reconcile, or update documentation.

- Compare documentation claims against the current codebase before editing.
- Fix stale paths, commands, feature descriptions, config names, and workflow steps.
- Keep docs concise; remove repeated rationale and examples that no longer help.
- Update nearby docs together when the same fact appears in multiple places.
- Run the smallest relevant docs, format, link, or static check after edits.
