# Session Boundary Matrix

Session routes that accept a `sessionId` must fail closed with `404` when the caller cannot prove access to the session's owner or business. Repo-backed shared-business access also requires route-level GitHub repo verification before the route forwards an internal auth context to the Session Durable Object.

| Surface                                                              | Auth                   | Boundary check                                                                                                                                                                                                            | Cross-business result                                                            |
| -------------------------------------------------------------------- | ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| `GET /api/sessions/:sessionId`                                       | authenticated          | `withSession()` checks `getSessionState()`, `canAccessSession()`, then `authorizeSessionRepoAccess()` before parent/child metadata reads.                                                                                 | `404`                                                                            |
| `GET /api/sessions/:sessionId/view`                                  | authenticated          | Fetches state, checks `canAccessSessionIdentity()`, verifies repo access, calls `getSessionView()` with auth headers, then re-checks returned owner/business. Parent/child metadata is bounded by matching `business_id`. | `404`                                                                            |
| `GET /api/sessions/:sessionId/events`                                | authenticated          | `withSession()` plus Session DO `listSessionEventsAuthed()` access check.                                                                                                                                                 | `404`                                                                            |
| `GET /api/sessions/:sessionId/events/history`                        | authenticated          | `withSession()` plus Session DO replay auth.                                                                                                                                                                              | `404`                                                                            |
| `GET /api/sessions/:sessionId/activity-timeline`                     | authenticated          | `withSession()` plus Session DO replay auth.                                                                                                                                                                              | `404`                                                                            |
| `GET /api/sessions/:sessionId/context`                               | authenticated          | `withSession()` plus Session DO context auth.                                                                                                                                                                             | `404`                                                                            |
| `GET /api/sessions/:sessionId/export`                                | authenticated          | `withSession()` plus Session DO export auth.                                                                                                                                                                              | `404`                                                                            |
| `POST /api/sessions/:sessionId/send`                                 | authenticated          | `withSession()` plus Session DO enqueue auth.                                                                                                                                                                             | `404`                                                                            |
| `POST /api/sessions/:sessionId/stop`                                 | authenticated          | `withSession()` before stop.                                                                                                                                                                                              | `404`                                                                            |
| `POST /api/sessions/:sessionId/respond`                              | authenticated          | `withSession()` before response forwarding.                                                                                                                                                                               | `404`                                                                            |
| `POST /api/sessions/:sessionId/create-pr`                            | authenticated          | `withSession()` before PR workflow.                                                                                                                                                                                       | `404`                                                                            |
| `PUT /api/sessions/:sessionId/repo`                                  | authenticated          | `withSession()` before repo update and repo installation gate.                                                                                                                                                            | `404`                                                                            |
| `GET /api/sessions/:sessionId/files`                                 | authenticated          | `withSession()` before context and GitHub token reads.                                                                                                                                                                    | `404`                                                                            |
| `GET/POST /api/sessions/:sessionId/feedback`                         | authenticated          | `withSession()` before feedback read/write and export auth for transcript generation.                                                                                                                                     | `404`                                                                            |
| `GET/POST /api/sessions/:sessionId/memory-feedback`                  | authenticated          | `withSession()` before memory feedback read/write.                                                                                                                                                                        | `404`                                                                            |
| `POST /api/sessions/:sessionId/child-sessions`                       | authenticated          | `withSession()` authorizes parent, then `validateChildSessionCreation()` requires parent business to match caller business unless admin.                                                                                  | `404` for parent access denial; child validation returns no cross-business plan. |
| `GET /api/sessions/:sessionId/child-sessions`                        | authenticated          | `withSession()` authorizes parent; `listChildSessionRows()` filters children by parent `business_id`.                                                                                                                     | `404` for parent access denial; foreign-business children omitted.               |
| `GET /api/sessions/:sessionId/child-sessions/:childSessionId/status` | authenticated          | `withSession()` authorizes parent; route checks parent id, and `getChildSessionStatusSummary()` requires child `business_id` to match parent business.                                                                    | `404`                                                                            |
| `GET /api/sessions/:sessionId/telemetry`                             | authenticated          | `authorizeObservabilitySession()` checks session access and repo access before D1 telemetry read.                                                                                                                         | `404`                                                                            |
| `GET /api/sessions/:sessionId/input-composition`                     | authenticated          | `withSession()` plus Session DO `inputComposition` route with `mcpBusinessScopeEnforced`.                                                                                                                                 | `404`                                                                            |
| `GET /api/sessions/:sessionId/sandbox-state`                         | authenticated          | `authorizeObservabilitySession()` then Session DO sandbox-state auth.                                                                                                                                                     | `404`                                                                            |
| `GET /api/sessions/:sessionId/artifacts/list`                        | authenticated          | `authorizeObservabilitySession()` then Session DO artifact-list auth.                                                                                                                                                     | `404`                                                                            |
| `GET /api/sessions/:sessionId/artifacts/:artifactId/:filename`       | anonymous or authed    | Anonymous callers require `artifactToken` query param; authenticated callers restricted to `user_session` mode, then `withSession()` checks ownership or shared-business repo access.                                     | `404`                                                                            |
| `GET /api/sessions/:sessionId/feedback/all`                          | authenticated          | `authorizeObservabilitySession()` before D1 feedback read.                                                                                                                                                                | `404`                                                                            |
| `GET /api/observability/runs?sessionId=...`                          | authenticated          | `queryPromptRuns()` owner-scopes non-admin aggregate reads; shared-business access is intentionally not used because per-session repo access cannot be proven for arbitrary result sets.                                  | Empty result                                                                     |
| `GET /api/observability/sessions`                                    | authenticated          | `searchSessions()` owner-scopes non-admin aggregate reads for the same reason.                                                                                                                                            | Empty result                                                                     |
| `POST /api/sessions/:sessionId/platform-llm/prompt-preparation`      | public sandbox         | Route requires a valid request body, then `validatePlatformLlmCapability()` forwards to the Session DO. The DO validates sandbox auth and one-shot capability against that session.                                       | Capability validation fails closed.                                              |
| `GET /api/sessions/:sessionId/clone-token`                           | public sandbox         | Session DO validates sandbox auth.                                                                                                                                                                                        | `404`/auth failure from DO                                                       |
| `GET /api/sessions/:sessionId/github-token`                          | public sandbox         | Session DO validates sandbox auth.                                                                                                                                                                                        | `404`/auth failure from DO                                                       |
| `POST /api/sessions/:sessionId/review-loop/reply`                    | public sandbox         | Session DO validates sandbox auth and requires an active sandbox before handling the review-loop reply request.                                                                                                           | `404`/auth failure from DO                                                       |
| `POST /api/sessions/:sessionId/pr-close`                             | public sandbox         | Session DO validates sandbox auth and enforces same-repo restriction before closing PR.                                                                                                                                   | `404`/auth failure from DO                                                       |
| `GET /api/sessions/:sessionId/ws`                                    | public browser/sandbox | Browser path authenticates and uses `withSession()`; sandbox path relies on Session DO sandbox-token auth.                                                                                                                | `404` or sandbox auth failure                                                    |
| `GET /api/users/me/feed/ws`                                          | public browser         | Authenticates user, requires business membership; resolves accessible repos and passes to SessionFeedDO. Cross-member delivery gated per-delta by repo access.                                                            | `403` without business; `503` if feed DO unbound                                 |
| Slack `message_deleted` event (stops session)                        | Slack signature        | `authorizeSessionCloseActor()` enforces owner-match or same-business with `sharedSessions: true`. Deletion actor resolved via global `getUserBySlackId` lookup; workspace boundary enforced by authorization function.    | Skipped (200 ok, `reason: "message_deleted"`)                                    |
| Slack thread follow-up `stop` command                                | Slack signature        | `authorizeSessionCloseActor()` enforces owner-match or same-business with `sharedSessions: true`. Actor resolved via global `getUserBySlackId` lookup.                                                                    | Skipped (200 ok)                                                                 |
| Slack interaction button `stop_session`                              | Slack signature        | `authorizeSessionCloseActor()` enforces owner-match or same-business with `sharedSessions: true`. Request loaded from D1 with team/channel/thread/session validation; actor resolved before authorization.                | Skipped (200 ok)                                                                 |

## Test Coverage

- `tests/test_cloudflare/session/do-auth-access.test.ts` covers Session DO owner, admin, shared-business, repo-gated shared-business, and cross-business denial behavior.
- `tests/test_cloudflare/session/business-boundary.test.ts` covers child-session business filtering/status denial and observability aggregate owner scoping.
- `tests/test_cloudflare/services/child-session.test.ts` covers child-session creation business mismatch and admin behavior.
- `tests/test_cloudflare/artifact-public-route.test.ts` covers artifact proxy dual auth: anonymous with token, cookie-authed session owner, shared-business repo access, and denial for non-user-session auth modes.
- `tests/test_cloudflare/slack-webhook-handler.test.ts` covers `authorizeSessionCloseActor` (owner allowed, same-business with `sharedSessions` enabled, same-business without `sharedSessions` rejected, cross-business rejected, synthetic actors rejected).
