# Engineering Memories

These are learned patterns from past work. Apply when relevant. Retrieval used structured relevance scoring.
## db-access
Type: convention

Database access is D1-only via prepared statements in DAO functions.

## routes-services
Type: rule

Routes call services and services call DAOs; never skip layers.

## no-shims
Type: convention

No backward-compatibility shims; update all call sites and remove old exports.
